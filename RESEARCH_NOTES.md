# Research Notes / MARGIN v5

## Creative thesis

`MARGIN`은 “하츠투하츠가 함께일 때 더 좋다”는 기존 결론을 반복하지 않고, 팀이 스스로 설명한 8인의 관계와 무대 가능성을 다음 질문으로 전환합니다.

> What can eight people communicate without explaining?

앨범의 핵심 visual rule은 `gaze / gesture / distance / shared object` 중 최소 하나가 멤버 사이에 실제 정보를 전달해야 한다는 것입니다. Berry line은 이 전달을 표시할 때만 사용합니다.

## Evidence boundary

- SM의 공식 team definition: 진심 어린 메시지, 신비롭고 아름다운 음악 세계, 팬들과 마음을 잇고 더 큰 “우리”로 나아가는 팀.
- NME 2026 interview: 멤버들이 말하지 않아도 서로의 상태를 파악한다는 Ian의 설명, 8명이 포메이션·스토리텔링·무대 상호작용의 가능성을 넓힌다는 Ye-on의 설명, Juun의 choreography experiment.
- `Choice → Friendship → Self-expression → Attention → Attitude → Togetherness → Recognition`은 공개된 활동을 바탕으로 만든 portfolio working interpretation이며 SM의 공식 세계관 정의가 아닙니다.
- 멤버별 `Composure / Warmth / Connection / Voice / Movement / Adaptation / Instinct / Clarity`는 공식 포지션이 아니라 visual direction에서의 기능 분배입니다.
