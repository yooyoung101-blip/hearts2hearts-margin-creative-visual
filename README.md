## v5 final edit

- Key Visual → Jacket → Styling/HMU → Package → Promotion의 채용 직무 증거를 앞세웠습니다.
- 공식 자료와 2026년 멤버 인터뷰를 다음 챕터의 근거로 사용했습니다.
- 숨겨진 8-signal scavenger hunt, progress HUD, locked final cover를 제거했습니다.
- `Art Director Desk`와 `Pair Relay`만 남겨 인터랙션이 production decision을 설명하도록 정리했습니다.
- 멤버별 컬러 배정 대신 proportion / surface / movement로 individuality를 구분했습니다.
- 모든 외부 reference image에 출처와 용도를 표시했습니다.

## 파일

- `index.html` — 전체 콘텐츠와 접근 가능한 마크업
- `styles.css` — 반응형 editorial visual system
- `app.js` — intro, index, progress, key visual view, production brief, pair relay
- `assets/` — 로컬 이미지 자산
- `RESEARCH_NOTES.md` — 근거, 해석 범위, 이미지 크레딧

## 주의

Hearts2Hearts 및 SM Entertainment와 공식적으로 연관된 결과물이 아닙니다. NME editorial image와 SMTOWN product image는 포트폴리오 분석·layout study용 reference이며, proposal의 최종 촬영 결과물로 표시하지 않습니다.
