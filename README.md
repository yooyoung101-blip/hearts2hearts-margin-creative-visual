# Hearts2Hearts — MARGIN

### A SIX-TRACK MINI ALBUM ABOUT RECOGNITION

> **EIGHT PEOPLE. ONE PRIVATE LANGUAGE.**  
> 말하지 않아도 서로를 알아보는 여덟 명.

**MARGIN**은 이미 가까워진 여덟 명이 말보다 먼저 서로를 알아보는 순간에서 시작합니다. 한 사람의 시선이 다음 사람의 몸짓으로 이어지고, 같은 물건과 동작이 멤버 사이를 이동합니다. 이때 두 사람 사이에 남겨진 거리는 빈 공간이 아니라 둘만 이해하는 신호가 오가는 장소가 됩니다.

## FROM CONNECTION TO RECOGNITION

Hearts2Hearts가 지금까지 선택, 첫 연결, 우정, 자기표현, 태도와 함께함으로 관계를 넓혀왔다면, 다음 장은 **RECOGNITION**입니다.

관계를 새로 만드는 이야기가 아니라, 이미 쌓인 관계 안에서 **말하지 않아도 상대의 감정과 상태를 알아보는 순간**을 그립니다. 여덟 명의 친밀함을 설명하는 대신 그들 사이에 실제로 무엇이 오가는지를 음악, 이미지와 physical object로 보여줍니다.

## THE SPACE BETWEEN US

`MARGIN`은 종이의 여백이자 멤버와 멤버, 이미지와 관객 사이에 남겨진 거리입니다. 이 공간을 비워두는 대신 시선, 제스처, 반복되는 동작, shared object와 짧은 문장으로 채웁니다.

여섯 곡은 silence, clipped rhythm, voice fragment와 서로에게 답하는 구조를 통해 하나의 private language를 만듭니다. 모든 이미지는 **한 멤버의 정보가 다른 멤버에게 전달되는 순간**을 포함한다는 하나의 visual rule을 공유합니다.

## WHY EIGHT

여덟 명은 하나의 관계를 다양한 리듬으로 보여줄 수 있는 구성입니다. `8 → 4+4 → 3+3+2 → 2×4 → 1×8`로 이어지는 formation 안에서 group, unit, pair와 individual이 같은 이야기를 서로 다른 거리로 반복합니다.

각 멤버는 **composure, warmth, connection, voice, movement, adaptation, instinct, clarity**라는 서로 다른 visual function을 맡습니다. 개인의 특징은 분명하게 남지만, 여덟 개의 기능이 연결될 때 하나의 Hearts2Hearts image가 완성됩니다.

## ONE CONCEPT, FIVE EXPERIENCES

|  |  |
| --- | --- |
| **KEY VISUAL** | Negative space와 이어지는 eye-line, 하나의 berry margin line으로 여덟 명 사이의 보이지 않는 신호를 드러냅니다. |
| **JACKET** | Group 8, pair, unit과 motion cut이 같은 gesture를 서로 다른 거리와 framing으로 이어받습니다. |
| **STYLING / HMU** | Ivory, graphite, berry를 멤버별 컬러가 아닌 texture와 surface의 변화로 사용합니다. |
| **PACKAGE** | Page margin, transparent layer, 접힌 메시지와 분리·결합되는 구성품으로 ‘사이의 공간’을 손으로 경험하게 합니다. |
| **PROMOTION** | Pair signal과 gesture relay를 순차 공개해 여덟 개의 조각이 하나의 관계로 완성되는 과정을 보여줍니다. |
