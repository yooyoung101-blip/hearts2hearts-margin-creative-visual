# Hearts2Hearts — SAME PAGE

서로 다른 여덟 개의 시선이 하나의 장면이 되는 순간.

`SAME PAGE`는 Hearts2Hearts가 지금까지 보여준 만남과 우정, 자기표현, 팀의 에너지 다음에 올 장면을 제안한 가상의 미니앨범입니다.

하츠투하츠의 강점은 여덟 명이라는 규모 자체가 아니라, 많은 포메이션과 멤버 사이의 관계를 한 화면 안에서 읽히게 만들 수 있다는 점에 있습니다. 이 기획은 그 강점을 ‘같은 생각’이 아니라 ‘서로 다른 시선이 완성하는 하나의 장면’으로 정의했습니다.

타이틀곡은 2000년대 댄스 팝의 선명한 후렴, 세련된 R&B 보컬, UK garage 리듬을 결합합니다. 뮤직비디오는 방송이 끝난 새벽의 스튜디오를 배경으로 여덟 멤버가 카메라와 큐카드를 이어받으며 자신들의 생방송을 완성하는 이야기입니다.

비주얼 코어는 `SOFT SIGNAL`입니다. 포인텔 니트, 워시드 저지, 데님, 시어 오간자처럼 촉감이 느껴지는 유스풀한 소재를 겹치고, 모든 룩을 통과하는 체리 레드 리본 한 줄을 멤버 사이의 신호로 사용합니다. 같은 규칙을 키 비주얼, MV 세트, 패키지와 프로모션까지 적용했습니다.
